How it uses Cookie Chain

  1. Wallet: Nightly (required). Add custom network RPC https://rpc.cookiescan.io if Nightly asks. Genesis 9wDaBRDgArEUpvhHxGguNkwozsZh4UpGZB9o2EoEcBB2.
  2. Read: Cookie RPC (getHealth, balance, slot, signatures) plus Cookiescan markets and Cookiebox /quote.
  3. Write: SPL Memo ping signed by Nightly. Fee is paid in COOK. Explorer: cookiescan.io.
  4. DeFi: live COOK→bCOOK route through Cookiebox CLMM. Swap UI uses the same aggregator judges use on cookiebox.app.
  5. Bridge COOK in: bridge.cookiescan.io if the wallet has no COOK for fees.
